Standard

    Core values

    One spring for everything that moves, two cubic curves for everything that fades. Split every element by property: position, size and scale ride the spring; opacity, blur and colour take the fade; corner radius runs on its own 200 ms clock. Click a curve to play it. The platform you pick applies to every card.

    Files

    The skill lives in this repo at .claude/skills/noon_sas_motion/, so Claude Code picks it up in this project automatically. Elsewhere, unzip the .skill into your project's .claude/skills/. Copy the tokens and helpers rather than re-typing the numbers.
